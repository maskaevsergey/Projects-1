# Спецодежда-ERP
## Перевод учёта спецодежды, инвентаря и спецоснастки из Excel в 1С:ERP

Дипломный проект: перевод учёта СИЗ и инвентаря из Excel в 1С:ERP с минимальным изменением типовой конфигурации и подготовкой к опытно промышленной эксплуатации (ОПЭ).

### Задача
Обеспечить полноценный учёт спецодежды, инвентаря и спецоснастки в 1С:ERP: контроль выдачи/возврата, сроков носки, списания по износу. Подготовить систему к ОПЭ.

### Что внутри
- `01 Проект 3 Документация бизнес-требований (BRD)01.docx` — бизнес  и пользовательские требования (контроль выдачи, сроки носки, списание, удобные формы, отчёты по подразделениям).
- `03 Проект 3 Реестр требований 01.docx` — функциональные разрывы между пожеланиями заказчика и типовой конфигурацией (индивидуальные карточки, специфические статусы, особые правила
списания).Решение с приоритетом типовых механизмов и минимальным вмешательством в ядро конфигурации.
- `04 Проект 3 ЧТЗ_ 01.docx` — постановка задачи программисту (объекты, алгоритмы, роли, статусы, интеграция с существующими справочниками).
- `05 Проект 3 ПМИ_01.xlsx` — программа и методика испытаний (ПМИ): сценарии тестирования, граничные условия, критерии приёмки.
- `06 Проект 3 Инструкция пользователя_01.docx` — инструкции пользователей (выдача/возврат/списание, отчёты, поиск).

### Результаты
- Требования формализованы, решение спроектировано.
- Задача поставлена, ПМИ и инструкции готовы.
- Проект готов к опытно промышленной эксплуатации.

### Стек и инструменты
- 1С:ERP
- Сбор и формализация требований
- Подготовка ПМИ, инструкций, шаблонов
- Word, Excel

### Как использовать
1. Ознакомьтесь с требованиями в `01 Проект 3 Документация бизнес-требований (BRD)01.docx`.
2. Проверьте функциональные разрывы в `03 Проект 3 Реестр требований 01.docx`.
3. Используйте `04 Проект 3 ЧТЗ_ 01.docx` как постановку задачи.
4. Проведите приёмочное тестирование по `05 Проект 3 ПМИ_01.xlsx`.
5. Обучите пользователей по инструкциям в `06 Проект 3 Инструкция пользователя_01.docx`.
